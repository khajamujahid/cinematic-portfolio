# Khaja Mohammed — Cinematic Portfolio

Dark cinematic personal portfolio for **Khaja Mohammed** (AI Software Engineer & Data Engineer).

Built with **Vite + React + TypeScript** and **Framer Motion**. Crimson accent on `#050505`, sticky hero cutout on desktop, sections: Home · About · Skills · Projects · Journey · Contact.

## Stack

- Vite 8 / React 19 / TypeScript
- Framer Motion (section reveals)
- Plain CSS variables (no UI kit)
- Deploy-ready for Vercel (`vercel.json` SPA rewrite)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
